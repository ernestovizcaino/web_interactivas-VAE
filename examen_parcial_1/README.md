# Primer examen parcial

Examen del primer parcial de Web Interactivas.

Es una app de reseñas de películas hecha con HTML, Bootstrap 5 y jQuery.

- `index.html` — listado de películas con filtros, búsqueda y favoritos
- `reseña.html` — detalle de una película

## Datos

Primero intenta traer las películas de la API de IMDb (imdb236 de RapidAPI). Si falla, las
carga de `PELICULAS.json`, y si tampoco funciona muestra un mensaje de error con un botón
para reintentar.
